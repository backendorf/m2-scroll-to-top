# Backendorf Scroll To Top (Magento 2)

A lightweight Magento 2 module that adds a configurable "Scroll to Top" button to storefront pages.

## Installation

- composer require backendorf/m2-scroll-to-top
- bin/magento module:enable Backendorf_ScrollToTop
- bin/magento setup:upgrade
- bin/magento cache:flush

## Configuration

- Admin: Stores > Configuration > Backendorf > ScrollToTop
- Options: Enable/Disable, Position, and Style.
